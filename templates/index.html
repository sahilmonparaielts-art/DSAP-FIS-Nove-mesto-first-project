WHAT TO NOTICE

  • Browser storage can be read by same-origin JavaScript.
  • Unsafe HTML rendering can let injected script run.
  • HttpOnly, CSP, safe rendering, and CSRF checks add layers of protection.
  • Encryption at rest does not stop active code from using an unlocked page.
